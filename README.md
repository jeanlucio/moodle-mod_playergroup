## English

**PlayerGroup** lets students autonomously form their own groups directly from the activity
page — no teacher intervention needed. It replaces manual group assignment with a self-service
experience that works for any course format: create or join a group (open, password-protected,
or invite-only), see who is in it, and let the teacher's gradebook and completion tracking
follow along automatically.

📚 **[Full documentation](https://jeanlucio.github.io/moodle-mod_playergroup/)** — features,
educational purpose, the PlayerGames ecosystem, usage guide, the full automated test suite and
coverage, and security details.

### 📦 Requirements

| Component | Version |
|-----------|---------|
| Moodle    | 4.5+    |
| PHP       | 8.2+    |

### 🛠️ Installation & Configuration

1. Download the `.zip` file or clone this repository.
2. Extract the folder into your Moodle `mod/` directory.
3. Rename the folder to `playergroup` (if necessary).
   Final path:
   `your-moodle/mod/playergroup/`
4. Visit **Site administration > Notifications** to complete installation.
5. Add a **PlayerGroup** activity to any course.

This plugin has no separate site-level settings to configure after installation — every
setting is configured by the teacher when adding the activity to a course, as covered in the
[Usage](https://jeanlucio.github.io/moodle-mod_playergroup/#usage) section of the full
documentation.

## Português

O **PlayerGroup** permite que estudantes formem seus próprios grupos de forma autônoma
diretamente na página da atividade — sem precisar de intervenção do professor. Ele substitui a
formação manual de grupos por uma experiência de autoatendimento que funciona em qualquer
formato de curso: criar ou entrar em um grupo (aberto, protegido por senha ou somente por
convite), ver quem está nele, e deixar que o livro de notas e a conclusão de atividade do
professor acompanhem tudo automaticamente.

📚 **[Documentação completa](https://jeanlucio.github.io/moodle-mod_playergroup/pt.html)** —
funcionalidades, finalidade educacional, ecossistema PlayerGames, guia de uso, a suíte completa
de testes automatizados e cobertura, e detalhes de segurança.

### 📦 Requisitos

| Componente | Versão |
|------------|--------|
| Moodle     | 4.5+   |
| PHP        | 8.2+   |

### 🛠️ Instalação e Configuração

1. Baixe o arquivo `.zip` ou clone este repositório.
2. Extraia a pasta dentro do diretório `mod/` do seu Moodle.
3. Renomeie a pasta para `playergroup` (se necessário).
   Caminho final:
   `seu-moodle/mod/playergroup/`
4. Acesse **Administração do site > Notificações** para concluir a instalação.
5. Adicione uma atividade **PlayerGroup** a qualquer curso.

Este plugin não tem configurações separadas em nível de site após a instalação — toda
configuração é feita pelo professor ao adicionar a atividade a um curso, conforme explicado na
seção [Como Usar](https://jeanlucio.github.io/moodle-mod_playergroup/pt.html#usage) da
documentação completa.
