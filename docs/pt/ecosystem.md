# 🕹️ Ecossistema PlayerGames

O PlayerGroup faz parte do ecossistema de gamificação **PlayerGames** para o Moodle. Juntos, esses plugins transformam o Moodle em uma experiência imersiva:

* **Bloco PlayerHUD:** O componente central de gamificação — XP, níveis, inventário, ranking, classes RPG e motor de história. Exibe o grupo do estudante como parte do seu perfil no jogo via a API pública do PlayerGroup.

  👉 <https://github.com/jeanlucio/moodle-block_playerhud>

* **Filtro PlayerHUD:** Permite inserir drops de itens por meio de shortcodes no conteúdo do curso.

  👉 <https://github.com/jeanlucio/moodle-filter_playerhud>

* **Restrição de Acesso PlayerHUD:** Restringe o acesso a atividades do curso com base no nível atual do estudante ou nos itens coletados.

  👉 <https://github.com/jeanlucio/moodle-availability_playerhud>

Veja o [hub do PlayerGames](https://jeanlucio.github.io/playergames/) para a família completa de plugins.
